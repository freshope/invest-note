문의하신 내용의 답변을 알림으로 바로 받아보세요.

새로워진 점
• 문의나 오류 신고에 답변이 달리거나 처리 상태가 바뀌면 알림으로 알려드려요. 받은 알림은 알림 목록에서 언제든 다시 확인할 수 있어요.
• 자산 추이 그래프를 일·주·월 단위로 바꿔 볼 수 있어요. 짧은 흐름과 긴 흐름을 원하는 대로 살펴보세요.
• 한국투자증권 거래내역서로 거래를 일괄등록할 수 있어요.
• 계좌 등록에 카카오페이증권을 추가했어요.

개선된 점
• 거래내역서를 올리면 이미 등록된 거래를 표시해 드려요. 같은 파일을 다시 올려도 중복 등록될 걱정이 줄었어요.
• 암호가 걸린 거래내역서 파일은 등록 전에 안내해 드려요.
• 탈퇴한 회원이 남긴 게시글과 댓글은 '탈퇴한 회원'으로 표시돼요.

해결된 문제
• 안드로이드에서 뒤로가기 버튼을 눌러도 앱이 종료되지 않던 문제를 고쳤어요. 이제 첫 화면에서 뒤로가기를 두 번 누르면 앱이 종료돼요.
• 문의·제보 글을 등록할 때 버튼을 연달아 누르면 같은 글이 여러 번 올라가던 문제를 고쳤어요.
• 거래내역서 일괄등록에서 일부 거래가 중복 등록되거나 등록에 실패하던 문제를 고쳤어요.

소중한 의견을 보내주세요. 더 나은 앱으로 보답하겠습니다.
